## 问题描述

有三根柱子 A、B、C。大小各不相同的盘子都在 A 上，B 和 C 为空。输入列表表示 A 上盘子**从底到顶**的实际顺序，列表末尾是顶盘。数字越大，盘子越大。初始时允许大盘压在小盘上。

每次只能取一根柱子的顶盘，将它移到空柱上，或移到比它大的顶盘上。初始就存在的大盘压小盘可以暂时保留，移动时只检查这一步放到目标柱上的盘子。

要求用最少的移动次数把所有盘子搬到 C，最终从底到顶按大小递减排列。输入第一行是盘子数 $n$（$0 \le n \le 8$），随后给出 $n$ 个互不相同的整数。输出最少移动次数和初始盘面，然后输出每一步的盘子编号、移动方向和移动后的盘面。三根柱子并排绘制，盘子从底座向上堆叠，盘子越大，画得越宽。竖线 `|` 表示该层露出的柱身。若无法到达目标，输出 `-1`。

例如，输入如下。

```text
3
1 3 2
```

一种最短方案是下面的四步，最终 C 从底到顶为 `[3, 2, 1]`。

```text
4
Initial:
 ==2==      |        |
===3===     |        |
  =1=       |        |
-------  -------  -------
   A        B        C

Step 1: disk 2, A -> B
   |        |        |
===3===     |        |
  =1=     ==2==      |
-------  -------  -------
   A        B        C

Step 2: disk 3, A -> C
   |        |        |
   |        |        |
  =1=     ==2==   ===3===
-------  -------  -------
   A        B        C

Step 3: disk 2, B -> C
   |        |        |
   |        |      ==2==
  =1=       |     ===3===
-------  -------  -------
   A        B        C

Step 4: disk 1, A -> C
   |        |       =1=
   |        |      ==2==
   |        |     ===3===
-------  -------  -------
   A        B        C
```

## 解题思路

经典递归要求待搬运的盘堆已经从底到顶按大小递减。这里初始顺序决定了哪些盘子可以先取，直接排序 A 会改变题目给定的状态。排序只用来构造目标状态。

把三根柱子的完整盘序视为一个状态，每次合法移动对应一条有向边。每条边的代价都是一步，因此用广度优先搜索（BFS）按移动次数逐层探索。边有方向，因为把盘子从初始的无序盘堆移走后，原样放回可能违反放置规则。

1. 用三个向量保存盘堆，向量末尾表示顶盘。把初始状态加入队列，并记录为已访问。
2. 从队列取出一个状态，枚举所有合法的起点和终点。对首次遇到的状态，记录它的前驱及本次移动，再加入队列。
3. 首次取出目标状态时，沿前驱回溯并反转步骤，即可得到一条最短路径。若队列耗尽，目标不可达。
4. 从初始盘面按顺序重放这条路径，每移动一个盘子，就输出这一步和更新后的三根柱子。

BFS 按路径长度递增处理状态。每一步都由放置规则生成，并且所有合法后继都会被枚举，因此首次到达目标的路径既合法，步数也最少。

## 复杂度分析

设可达状态数为 $S$。每个状态最多枚举六种移动。复制或比较状态需要 $O(n)$ 时间，使用 `std::map` 查重需要 $O(\log(S+1))$ 次比较。搜索时间为 $O(nS\log(S+1))$，空间为 $O(nS)$。

初始盘序无序时，同一组盘子所在的柱子相同，盘序仍可能不同。为了给 $S$ 估计上界，可以按 A 底部从未移动的盘子数 $k$ 分类。这 $k$ 个盘子构成固定的初始前缀。其余盘子在各柱上的相对顺序由合法放置规则确定，所以对给定的 $k$，至多有 $3^{n-k}$ 种状态。对所有 $k$ 求和，得到 $S = O(3^n)$。这种搜索适合小规模输入。
